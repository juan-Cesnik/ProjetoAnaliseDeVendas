Dicionário de variáveis:

- `Row ID`: Identificador único sequencial de cada registro na base de dados (1 a 9800)[cite: 1]
- `Order ID`: Código identificador único do pedido de compra (ex: CA-2017-152156)[cite: 1]
- `Order Date`: Data em que o pedido foi realizado pelo cliente no formato DD/MM/YYYY[cite: 1]
- `Ship Date`: Data em que o pedido foi despachado para entrega no formato DD/MM/YYYY[cite: 1]
- `Ship Mode`: Modalidade de envio do pedido — Standard Class = Classe padrão, Second Class = Segunda classe, First Class = Primeira classe, Same Day = Entrega no mesmo dia[cite: 1]
- `Customer ID`: Código identificador único do cliente (ex: CG-12520)[cite: 1]
- `Customer Name`: Nome completo do cliente[cite: 1]
- `Segment`: Segmento de mercado do cliente — Consumer = Consumidor final, Corporate = Corporativo, Home Office = Escritório doméstico[cite: 1]
- `Country`: País onde a transação foi realizada (United States)[cite: 1]
- `City`: Cidade de destino da entrega do pedido[cite: 1]
- `State`: Estado americano de destino da entrega[cite: 1]
- `Postal Code`: Código de endereçamento postal (CEP) da localidade de entrega[cite: 1]
- `Region`: Região geográfica dos Estados Unidos — South = Sul, West = Oeste, Central = Centro, East = Leste[cite: 1]
- `Product ID`: Código identificador único do produto (ex: FUR-BO-10001798)[cite: 1]
- `Category`: Macro-categoria do produto — Furniture = Móveis, Office Supplies = Materiais de escritório, Technology = Tecnologia[cite: 1]
- `Sub-Category`: Subcategoria do produto — Bookcases = Estantes, Chairs = Cadeiras, Labels = Etiquetas, Tables = Mesas, Storage = Armazenamento, Furnishings = Decoração/Mobiliário, Art = Arte, Phones = Telefones, Binders = Fichários/Pastas, Appliances = Eletrodomésticos, Paper = Papel, Accessories = Acessórios, Envelopes = Envelopes, Fasteners = Prendedores/Clipes, Supplies = Suprimentos, Machines = Máquinas, Copiers = Copiadoras[cite: 1]
- `Product Name`: Nome comercial detalhado do produto[cite: 1]
- `Sales`: Valor total faturado na venda do item em dólares americanos (USD)[cite: 1]
