Dicionário de variáveis:
Row ID: Identificador único sequencial de cada registro na base de dados (1 a 9800)
Order ID: Código identificador único do pedido de compra (ex: CA-2017-152156)
Order Date: Data em que o pedido foi realizado pelo cliente (formato DD/MM/YYYY)
Ship Date: Data em que o pedido foi despachado para entrega (formato DD/MM/YYYY)
Ship Mode: Modalidade de envio do pedido — Standard Class = Classe padrão, Second Class = Segunda classe, First Class = Primeira classe, Same Day = Entrega no mesmo dia
Customer ID: Código identificador único do cliente (ex: CG-12520)
Customer Name: Nome completo do cliente
Segment: Segmento de mercado do cliente — Consumer = Consumidor final, Corporate = Corporativo, Home Office = Escritório doméstico
Country: País onde a transação foi realizada (United States)
City: Cidade de destino da entrega (ex: Henderson, Los Angeles, Chicago)
State: Estado de destino da entrega (ex: Kentucky, California, Florida)
Postal Code: Código de endereçamento postal (CEP) da localidade de entrega
Region: Região geográfica dos Estados Unidos — South = Sul, West = Oeste, Central = Centro, East = Leste
Product ID: Código identificador único do produto (ex: FUR-BO-10001798)
Category: Macro-categoria do produto — Furniture = Móveis, Office Supplies = Materiais de escritório, Technology = Tecnologia
Sub-Category: Subcategoria do produto — Bookcases = Estantes, Chairs = Cadeiras, Labels = Etiquetas, Tables = Mesas, Storage = Armazenamento, Furnishings = Decoração/Mobiliário, Art = Arte, Phones = Telefones, Binders = Fichários/Pastas, Appliances = Eletrodomésticos, Paper = Papel, Accessories = Acessórios, Envelopes = Envelopes, Fasteners = Prendedores/Clipes, Supplies = Suprimentos, Machines = Máquinas, Copiers = Copiadoras
Product Name: Nome comercial detalhado do produto
Sales: Valor total faturado na venda do item em dólares americanos (USD)
